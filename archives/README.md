# Archives

`boutons-historiques` conserve les premiers dessins et bandes du bouton tricolore. L'application utilise désormais les ressources des dossiers `bouton/clair` et `bouton/sombre`.

`outils-historiques` conserve les anciens scripts de lancement et de mise à jour à titre de référence ; ils ne font pas partie des distributions actuelles.

`local` contient les anciens journaux, raccourcis et données d'essai propres à cette machine. Il n'est pas suivi par Git. Les anciens paquets sont conservés dans `release/archives`, également hors Git.
